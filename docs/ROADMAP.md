# 开发路线

## v0.1 已完成

独立源码、六页面交互、资料/日志/体重的本地保存、三视角临时预览、规则模板、演示减量确认、模板版本快照、自动测试、静态构建、MIT和贡献说明。

## v0.2 训练记录与基础规则

补齐时长、具体设备、限制与禁忌资料；逐条编辑/删除记录；动作ID、教学、替代与规则审查；版本历史和任意版本恢复；导出/导入及迁移。

## v0.3 后端与账户

认证、数据库、所有权校验、私有照片、质量检查、保留期、删除任务。用两个账号验证隔离；离线保存和重复请求验证。先比较LiftCut/GymCoach工程适配成本，再决定是否局部复用。

## v0.4 真实AI

服务端密钥、结构化输出、设备/限制校验、生成失败回退、草稿编辑与确认。个人营养计算使用审查公式和可追溯数据。照片生成观察/局限/建议，数据不足返回无法判断。

## 验证后开放

体脂范围、长期照片变化解读和视频动作辅助。单独建立参照数据与评估，不从姿态关键点直接推出体脂或肌肉量。
