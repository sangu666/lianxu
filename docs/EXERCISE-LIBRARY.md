# 第 4 步：动作库与文字教学

## 本版可以做什么

- 动作资料库：18 个练序模板动作与 1,324 条社区资料，支持关键词、部位、主要设备筛选及每页 24 条的分页。
- 社区动作优先显示中文名称，详情保留英文原名供核对，中英文都能搜索。显示中文步骤、英文原文、主要与辅助肌群、设备及来源。设备同义项在筛选时合并，原数据不改写。
- 模板动作提供中文名称、步骤、容易忽略的要点和记录单位。计划与训练记录都能打开详情；弹层关闭后保留未保存的录入内容。
- 手机入口在底栏“更多 → 动作资料库”，桌面在侧边栏。

## 数据来源与许可

采用用户指定的 [hasaneyldrm/exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset)，固定提交 `7455efae41b330c265e7cd4b78dfa848e7ce5ebd`。

原始 `exercises.json` 的 SHA256 为 `656634224b8977b99a6d765470ee123260d4979715eaa4e7c0b7c8bb0d79f93d`。

只导入 MIT 授权的文字与元数据。上游图片、GIF 和视频采用单独授权，当前没有复制、热链接或打包媒体。完整原许可证及 NOTICE 保留在 `public/data/`，说明见根目录 `THIRD_PARTY_NOTICES.md`。这份库已经覆盖当前查阅需求，暂不叠加其他来源，以免动作重复和许可关系难以维护。

社区资料的中文翻译和标签没有逐项专业审校，不能作为个人训练处方。上游只标注主要设备，并不保证设备清单完整，也没有训练记录单位；因此它们只用于查阅，不加入自动排课。18 个模板动作的基础文字提示由练序编写，同样尚未经过专业教练逐项审校。没有实现视频动作纠正或真实 AI 教学。

## 代码阅读顺序

1. `public/exercise-catalog.js`：阅读 `BUILTIN_EXERCISES` 与 `PLAN_SLOTS`，理解动作资料与模板位置如何分离；单位 `reps` 是次数、`seconds` 是秒，社区的 `unspecified` 表示未知。
2. `public/profile-rules.js`：从统一目录读取名称、设备及动作标签，保持第 3 步筛选顺序；社区库不参与此函数。
3. `public/exercise-view.js`：数据仅在动作库页面动态加载；`searchExercises` 限制单页数量，外部文本转义后显示。详情弹层独立于训练页面，避免刷新表单；固定顶部标题与右上角关闭按钮，长说明仅滚动正文。
4. `public/workouts.js`：新训练使用 `lianxu:` 稳定编号；`canonicalExerciseId` 仅在上次成绩查询时映射已知旧名称，不修改历史快照。未知名称不模糊合并，单位仍须一致。
5. `scripts/import-exercises.mjs`：先校验固定源文件散列，再按白名单输出公开字段；不执行上游源码。`scripts/exercise-names-zh.mjs` 使用常见术语、限定词及整名例外生成 `nameZh`；原字段 `name` 和 ID 不变。未知词阻止导入，避免新版数据静默回退英文。译名尚未经过逐项专业审校，可按英文原名和步骤继续修订。
6. `test/exercise-library.test.js`：学习许可数据边界、错误输入、兼容旧记录、外部文本转义与加载失败的验证方法。

## 重新导入

从上述固定提交下载原始 `exercises.json` 到忽略目录 `work/exercises-source/`，再执行：

```powershell
node scripts/import-exercises.mjs work/exercises-source/exercises.json
npm run check
npm run format:check
```

来源改变时导入器会拒绝写入；升级必须重新审查许可、字段及单位，再显式更新固定提交与散列。产物 `public/data/exercises.js` 约 1.6 MB，只在动作库页面加载，并随静态构建发布；个人训练备份不包含此目录。

## 验收清单

- 初次加载显示 1,342 个动作；“哑铃 + 肩部 + 哑铃设备”可同时找到模板与社区资料。
- 下一页、上一页、无结果提示正常；加载失败可重试。
- 社区详情有中文步骤、英文原文及来源，没有媒体。
- 计划和训练详情支持关闭、Escape 和焦点恢复；录入负重后打开并关闭详情，原输入仍在。
- 新旧动作身份匹配、次数与秒数区分、计划筛选及备份往返自动验证通过。
- 手机五入口底栏保持原布局，动作资料库位于“更多”，页面和弹层没有横向溢出。
