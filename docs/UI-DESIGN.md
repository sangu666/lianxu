# 练序 · iOS 风格界面设计与开发说明

## 设计目标

用清晰、克制的视觉层级帮助用户完成训练。采用 iOS 常见的大标题、分组内容、分段选择器与底部导航思路，仍交付现有 Web 应用，不是原生 iOS 工程或 Apple 官方认证设计。

此次覆盖今日概览、身体与资料、训练计划、训练记录、饮食建议和进展回顾。训练存储、备份与迁移沿用现有模块。营养数值继续明确为演示；AI 未接入的状态始终可见。

## 视觉规范

| 元素       | 规范                               | 原因                               |
| ---------- | ---------------------------------- | ---------------------------------- |
| 页面背景   | `#F5F5F7`                          | 区分白色分组内容，减少边框密度     |
| 主文字     | `#20232B`                          | 保持正文清晰                       |
| 次要文字   | `#656B77`                          | 用于说明和标签，保留可读对比       |
| 主操作     | `#245BDA`，白色文字                | 突出保存、开始等主要操作           |
| 首页训练卡 | `#182846`                          | 聚焦当前训练入口                   |
| 删除操作   | 红色文字与明确动作名称             | 危险操作不与主操作混淆             |
| 字体       | 系统字体优先；中文使用设备可用字体 | 无需下载外部字体；iOS 优先系统字体 |
| 标题       | 桌面最大 38px；手机 30px           | 建立页面层级，长标题允许换行       |
| 内容分组   | 20–28px 内边距；22–28px 圆角       | 通过留白建立关系                   |
| 控件       | 最小 44px 高度，手机输入文字 16px  | 降低误触，避免小字号输入体验       |
| 动效       | 180ms 按压与颜色反馈               | 操作立即可感知；减少动态偏好下关闭 |

颜色令牌集中在 `public/style.css` 的 `:root`。`--green` 是历史兼容名称，当前代表蓝色主操作色，避免为改名影响现有页面引用。本版使用浅色主题，深色主题留待独立设计与验收。

## 导航与页面组织

- 桌面：固定侧栏保留六个入口；内容区有统一标题和分组卡片。
- 手机：底栏为今日、计划、记录、进展、更多；更多展开身体资料与饮食入口。
- 更多菜单支持点击外部、Escape 和路由切换收起。
- 手机底栏使用安全区内边距；正文和浮动提示预留底栏空间。
- 计划训练日用分段选择器区分当前选择；不改变原有训练日逻辑。

首页进度环按上海日期、周一至今天的已完成训练次数统计，分母为资料中每周训练次数。进行中的训练不计入；超过目标后数字继续显示，环形填充最多 100%。环提供文字及辅助技术标签，排期仍标注为示例。

## 代码学习与维护

`public/index.html` 定义品牌、外壳和固定内容区；`public/app.js` 渲染导航与首页进度；`public/style.css` 控制六页共用组件及断点。关键视觉规则与新变量有中文注释。训练事件仍由 `public/workout-view.js` 处理。

先改令牌，再调整共用组件，最后修改页面特殊规则。布局使用 `minmax(0, 1fr)`，允许长内容收缩与换行，避免手机横向溢出。保留焦点描边、表单标签、确认取消入口和减少动态设置。
