# 当前架构

当前是本地可运行静态原型，不是Next.js生产工程。

`public/app.js`负责路由、视图、浏览器存储和事件；`public/core.js`负责资料验证、模板、恢复提案和版本快照；`scripts/serve.mjs`只提供public目录静态资源，无数据API；`scripts/build.mjs`将前端复制到dist。

浏览器记录不进入仓库或构建。存储损坏时回到虚构示例；禁用存储时显示临时保存提示。照片只用Object URL预览，移除或刷新释放，不进行AI分析。

训练与营养数字是交互示例，不是经审查的处方。照片结论目前不可用。

后续正式工程建议采用TypeScript、服务端API、PostgreSQL、私有对象存储与异步任务。模型适配器与规则校验分开，照片观察独立于身体数据测量，确认后保存不可变计划版本。当前尚未锁定生产框架/供应商。
