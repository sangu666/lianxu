## 产品方向

面向居家训练新手及有一定经验的健身房用户，逐步实现资料采集、身体照片观察、个性化训练与饮食建议、训练记录、体重与照片追踪、计划调整。

现阶段是原生 JavaScript 本地 Web 原型，没有账户、后端或真实 AI。训练计划使用规则模板；饮食数值是演示数据。照片通过本地临时预览展示，刷新后清除，不上传。体脂估计和肌肉短板分析尚未实现。
