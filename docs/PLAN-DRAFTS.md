# 全库选动作与计划草稿导入

## 使用步骤

1. 打开“训练计划”，点击“替换动作 → 从全部动作中选择”。支持搜索、部位与设备筛选、分页，共 1,342 个动作，不限同类。目录条目显示来源和编号，避免同名动作混淆。
2. 选择动作后确认组数、次数或秒数、目标上下限、休息时间和安排理由。设备、动作限制、单位或部位变化有提醒，核对后再勾选保存。社区资料单位未知，必须明确选择；单位改变时清空旧目标。
3. “从全库新增动作”可添加动作；“编辑目标”可修改已有动作组次及理由。确认建立新版本，后续新训练生效，进行中和已完成训练的快照保留。
4. “导入计划草稿”支持粘贴 JSON 或选择本地 JSON 文件，先检查和预览，再确认导入。修改文本后旧预览失效。超过 256 KB、未知编号、重复动作、无效目标会拒绝，当前计划不变。
5. 下载当前计划草稿作为编辑起点。导入弹层内可下载格式示例和完整动作编号清单；外部 AI 可以按这个格式返回草稿，动作必须引用清单中的稳定 ID。没有实现自动调用 AI 或照片分析。

完整文件示例见 `PLAN-DRAFT-EXAMPLE.json`；示例数值仅展示格式，不是个人处方。

## 草稿约定

- `format` 固定为 `lianxu-plan-draft`，`version` 固定为 `1`，它是草稿格式版本，与训练计划版本不同。
- `title` 为 1–120 字；`origin` 为 `manual` 或 `ai-draft`。后者仅表示外部草稿来源，不证明练序验证或生成了 AI 建议。
- `days` 支持 1–7 个训练日，与个人资料频率不同会提醒；每个训练日包含名称及 1–20 个动作。
- 每个动作包含 `exerciseId`、`unit`、`sets`、`targetMin`、`targetMax`、`restSeconds` 和可选 `reason`。
- `exerciseId` 必须来自目录，不按名称、翻译或肌群近似猜测。名称从目录读取，传入名称不覆盖它；存入版本后名称成为快照。
- `unit` 必须明确为 `reps`（次）或 `seconds`（秒）。模板计时动作不能改成次数；社区动作由用户明确选择。
- 组数 1–10；次数目标 1–100；秒数目标 1–3600；下限不超过上限；休息时间 0–600 秒；理由最多 1000 字。全部数字必须为整数。
- 同一天不允许重复同一动作 ID。不同来源、不同变式可能同名，保留独立编号及成绩，不根据名字合并。

## 保存与恢复

状态新增可选 `editablePlan`，包含标题、来源、训练日和逐动作目标；每次确认把独立副本写入历史。旧状态没有这个字段时仍计算规则模板与旧替换清单，不做读取迁移或改写。

新训练复制稳定动作 ID、名称、单位与 `prescription`（计划目标），实际完成组仍存在 `sets`，不能把计划目标当成已完成成绩。上次成绩只匹配动作 ID 与单位。

刷新和完整备份恢复保留自定义计划、来源及目标；合并训练仍不覆盖当前计划。普通资料修改或恢复规则模板会清除当前自定义计划，旧版本与训练保留。自定义计划不适用旧模板的“一键减量”演示，会提示逐动作编辑。

保存仍使用原有失败回滚与跨页面冲突检查。草稿预览不写存储；确认失败时保留当前计划并显示错误。下载计划草稿不包含身体资料、照片或训练成绩，仍可能包含用户自己填写的安排理由，应自行保管。

## 代码学习

- `public/plan-actions.js`：计划目标的共同范围校验，训练快照复用同一规则。
- `public/plan-document.js`：精确匹配动作 ID、草稿白名单解析、条件提醒、统一读取当前计划与建立新版本。
- `public/data/plan-index.js`：从固定来源生成的轻量目录，约 118 KB；完整教学步骤约 1.7 MB，按需加载。许可同原文字数据，未导入媒体。
- `public/plan-editor-view.js`：全库选择与导入弹层、预览失效、单位切换、文件异步读取及明确确认。
- `public/replacement-view.js`：保留推荐替代入口，另接全库选择；已有自定义计划先确认逐动作目标。
- `public/workout-view.js` 与 `workouts.js`：开始训练时复制计划目标与动作身份，保留旧训练兼容。
- `public/storage.js`：当前计划与历史计划都校验，旧备份缺省兼容。
- `test/plan-drafts.test.js`：全库索引、草稿错误、单位边界、版本与备份、快照及写入失败的验证。

运行 `npm run check`、`npm run format:check`。本轮 64 项测试、构建与格式检查通过；浏览器验证全库搜索、社区动作确认、教学入口、JSON错误、预览失效、导入与刷新、旧训练目标保留、新训练社区 ID 与计时单位，以及手机弹层无横向溢出。
