# v0.2 验收与代码学习

## 已验证

自动测试覆盖旧记录迁移、日期校验、ID唯一性、时间顺序、组操作、刷新恢复、容量不足、读回失败、并发覆盖拒绝、完整备份往返及合并冲突。

页面使用虚构数据验证：开始训练→保存一组→刷新恢复→修改次数→完成→下一次对照并沿用上次成绩→导出备份→重复合并跳过→删除测试组→完整恢复。检查375px手机布局与桌面布局；不上传个人记录。

## 你可以亲自试用

1. 在E盘项目运行npm start，打开本地地址，进入训练记录。
2. 开始训练，按自己实际完成情况填写，逐组点击保存。未保存的表单不是已记录内容。
3. 刷新，确认训练与已保存组仍在。编辑一组并保存。
4. 完成训练，再开始一次，检查上次成绩。疼痛标记需要根据这次体验重新填写。
5. 导出备份后导入同一文件，合并应显示跳过重复，不增加训练。
6. 用虚构训练验证删除与恢复；不要拿唯一一份真实记录试删除。

真人训练试用尚需你实际完成。自动测试与页面模拟不能替代使用体验反馈。

## 学习顺序

1. public/workouts.js：数据结构、纯函数、复制后校验，避免直接改原对象。
2. public/storage.js：保存为何先检查版本与并发，为什么写入后还要读回。
3. public/workout-view.js：表单值如何转成数字、编辑ID如何避免误新增、确认与取消。
4. public/app.js：全局状态只在保存成功后替换，浏览器存储是有失败可能的外部依赖。
5. test/workout-flow.test.js：用虚构输入和内存存储，验证失败路径与恢复。

训练页面仍用模板字符串，没有引入组件框架。可继续把表单和历史列表拆成小视图函数；先保持行为稳定再做结构重构。
