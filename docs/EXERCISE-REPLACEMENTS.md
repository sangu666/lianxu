# 第 5 步：动作替代与版本保存

## 如何使用

打开“训练计划”，在对应动作下点击“替换动作”。选择框展示当前可用候选、设备、单位与替代说明。点击“确认替换为……”才保存；关闭或按 Escape 不改计划。

确认会建立新计划版本，只改变所选训练日的这个动作，组数、次数目标与粗略时间不变。进行中和已完成训练仍使用开始时的版本、动作名称、动作编号和组成绩；下一次新训练才使用替换结果。不同动作的负重不等同，上次成绩按动作身份分别查询。

## 本次支持范围

从 18 个已整理模板动作建立四组明确关系：

| 动作位置 | 可替代动作                                         |
| -------- | -------------------------------------------------- |
| 蹲类     | 高脚杯深蹲、腿举、自重深蹲                         |
| 水平推   | 哑铃地板卧推、器械推胸、靠墙俯卧撑                 |
| 水平拉   | 单臂哑铃划船、坐姿划船、坐姿弹力带划船             |
| 髋铰链   | 哑铃罗马尼亚硬拉、杠铃罗马尼亚硬拉、自重髋铰链练习 |

候选必须满足明确的可用设备、动作限制、同类关系、相同记录单位，以及当天不重复。偏好只决定排列顺序，不能放宽其他条件。选择框可展开查看不可选原因。

其他模板动作暂未整理同类替代关系，会明确提示无候选。垂直拉不因目标肌群相似就替换为水平划船，臀桥不直接替换为腿弯举；社区库仍只供查阅。规则并不证明难度、刺激或安全性等同，也不进行疾病或康复判断。GIF/视频模块仍待后续实现。

## 数据与兼容

完整状态新增可选字段 `planOverrides`，每项为：

```js
{
  dayIndex: 0,                       // 训练日下标，从0开始。
  fromId: 'lianxu:goblet-squat',     // 规则模板原来的动作，用作固定锚点。
  toId: 'lianxu:bodyweight-squat',   // 这个版本手动确认的动作。
}
```

多次替换始终锚定基础模板，选回原动作时删除该项。版本历史保存相应资料与替换清单的独立副本。备份、完整恢复和刷新恢复均携带清单；合并训练仍只添加训练，不覆盖当前计划。旧备份没有此字段时按空清单计算，不改写原始对象。

保存或导入时重新验证清单，拒绝重复项、未知动作、无关动作、不满足设备/限制的目标，以及原动作已不在基础模板中的条目。普通修改资料会重新筛选基础模板并清除当前替换，旧历史和训练记录保留；接受减量演示显式保留替换，恢复基础模板则清除。

所有写入使用已有 `commitState` / `persistState` 流程。空间不足、写入失败或跨页面冲突时保留当前已保存计划，选择框显示错误；不会把失败的替换显示为已保存。

## 学习代码顺序

1. `public/exercise-replacements.js`：`groups` 表达业务关系；`replacementOptions` 把设备、限制、重复等原因逐条列出；`applyPlanOverrides` 校验并应用清单。
2. `public/core.js`：`createPlan` 先生成基础计划再应用替换；`replacePlanExercise` 检查打开时的版本与动作，返回新状态，不修改旧状态。
3. `public/storage.js`：完整状态与版本历史都验证替换字段，保持旧备份兼容。
4. `public/replacement-view.js`：弹层仅显示候选，确认时再次读取状态并校验，保存成功后关闭，失败时保留错误。
5. `test/replacements.test.js`：候选过滤、版本快照、换回原动作、过期选择、备份往返及写入失败场景。

## 验证结果

55 项自动测试通过，语法、构建、格式检查通过。浏览器验证取消与焦点恢复、确认保存、刷新恢复、无候选解释，以及先开始训练再替换计划时保留旧训练、下一次新训练采用新动作且不混用重量成绩。390 像素手机页面与弹层无横向溢出。试用数据为独立本地端口的虚构记录。
