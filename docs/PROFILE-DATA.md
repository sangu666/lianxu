# 第 3 步：个人资料与训练条件

## 本地新增能力

身体与资料页面新增设备多选、单次训练时间、动作偏好、暂不安排的动作类型和补充备注。保存后创建新计划版本；这些明确条件参与规则模板筛选。当前仍没有真实 AI、诊断、康复方案或个人营养计算。

## 新字段

| 字段                 | 数据格式                                  | 含义                                                                 |
| -------------------- | ----------------------------------------- | -------------------------------------------------------------------- |
| `availableEquipment` | 稳定编号数组                              | 实际可用的自重、哑铃、杠铃、弹力带及指定器械；空数组表示没有勾选设备 |
| `sessionMinutes`     | 20 / 30 / 45 / 60 / 90                    | 单次可用时间，单位分钟                                               |
| `movementPreference` | any / machines / freeweights / bodyweight | 无偏好、器械、自由重量、自重优先                                     |
| `excludedPatterns`   | 稳定编号数组                              | 明确暂不安排的动作类型；空数组表示没有主动排除                       |
| `restrictionNotes`   | 最多 1000 字的字符串                      | 用户补充备注，仅保存和回看，不参与文本推断                           |

完整选项定义位于 `public/profile-rules.js`。训练环境 `equipment` 继续决定基础模板；设备多选是实际筛选条件，改变环境不会自动勾选设备。

## 筛选顺序

1. 按原有经验、频率和环境确定基础训练日及动作位置。
2. 候选动作必须拥有相应设备，且不包含任何已排除标签。
3. 在符合条件的候选动作中，优先用户偏好，其次沿用原模板；同一天不重复动作。
4. 缺少设备、主动排除及候选重复分别给出原因，不用不符合条件的动作填补。
5. 使用“热身 5 分钟 + 每组约 3 分钟（含休息）”作粗略预算，时间不足时保留前面的动作，明确提示未覆盖全部模板。

时间估计是演示规则，不是实际计时或完成保证。当前缩减规则不会在多个训练日之间自动补齐遗漏动作，完整规则审查留待后续步骤。候选清单只是本步筛选所需的最小规则数据，还不是包含教学的完整动作库。

无动作的训练日显示提示，计划页记录按钮禁用；训练记录页也会拒绝创建空训练。已开始训练继续使用原快照，不会因新资料变化而被静默替换。

## 旧数据与备份

新字段允许缺省，兼容旧版资料与历史快照。缺省时推定原模板设备、60 分钟、无偏好、无排除和空备注，只用于显示与计算；读取不会修改原始 JSON，也不会自动建立新计划版本。

保存表单才把新字段加入当前资料和新版本快照。新版校验同时检查当前资料与历史资料。完整备份保留新字段，训练合并仍不覆盖当前资料。原有存储键、备份格式版本与训练结构继续使用 v2。

旧版 v0.2 程序没有本步筛选规则，即使可以读取备份，也不会应用新条件；请用包含本步改动的程序继续编辑。补充备注进入本地备份，备份应妥善保管，不提交真实资料到 GitHub。

## 验收与代码学习

自动测试新增 9 项，涵盖旧数据不改写、设备筛选、偏好优先级、排除标签、时间预算、空模板、非法字段、版本快照与备份往返、备注不参与筛选。

浏览器使用虚构资料验证保存、刷新恢复、模板变化、旧训练快照保留和空模板拒绝，并检查手机布局。

建议先看 `trainingPreferences` 理解兼容缺省字段，再看 `validateTrainingPreferences` 理解输入校验，最后看 `selectExercises` 理解候选筛选与优先级。公开函数和关键变量已附中文说明。
