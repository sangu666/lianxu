# 第六步：写入回执与待同步队列

本机账户模式的资料、计划、训练（含组记录）、训练删除和体重保存现已支持请求编号与成功回执。解决的是重复点击、网络中断及响应丢失后无法判断是否提交的问题，仍保留原来的版本冲突检查和不可变训练快照。

## 使用方式

正常保存时自动生成随机请求 UUID，先暂存再发送；收到成功响应才更新页面事实并移除待同步请求。连接中断或服务不可用时，页面上方出现“待同步，尚未确认保存”，表单输入保留。

1. 恢复本机服务或网络后，点击“重试同步并刷新”。服务器用原编号核对是否已成功，不会再产生一份计划、训练或体重。
2. 待同步请求在当前浏览器保存，刷新后仍存在；重新登录同一账户后可以继续处理。其他账户不读取或发送此请求。
3. 版本冲突或无效内容显示“需要核对”。下载原请求，核对服务端记录后，可放弃本地请求并刷新，再重新编辑。不会自动覆盖另一页面的数据。
4. 放弃只删除浏览器中的请求，不删除数据库记录；响应丢失时服务端可能已提交，操作前有明确提示。

每个账户最多一项未完成请求，未处理前暂停后续写入和备份迁移。恢复联网只提示重试，不自动提交或刷新正在编辑的表单。退出不清空队列，重新登录原账户后恢复；清除浏览器网站数据会删除本地请求，应先下载留存。

## 数据归属与边界

本轮新增的账户专属 localStorage 键为 `lianxu.account-outbox.v1:账户UUID`。其中仅保存这一项操作的请求体、路径、方法、编号、状态、创建时刻与错误说明；不保存会话令牌、CSRF、密码或照片，不缓存整个账户数据库。待同步请求可能含训练资料或健康记录，应妥善保管下载文件。

本轮为已有页面的失败保存提供恢复能力，不是完整离线应用：刷新时仍需后端读取账户事实，不支持断网后连续完成多项互相依赖的训练修改，也不支持跨设备同步队列。旧浏览器训练存储、原始备份和照片预览不变。真实 AI 尚未接入。

浏览器使用 Web Locks 串行处理同账户请求，防止两个标签页争抢队列；存储事件只更新同步提示，不重建表单。缺少 Web Locks、存储失败或队列损坏时，阻止发送并保留原内容。队列原请求最多 1 MB；服务器接口原有请求体限制仍适用，过大请求拒绝。请求等待上限 20 秒，超时后可能已提交，仍使用原编号重试。

## 服务端事务

`Idempotency-Key` 请求头为 UUID。新页面的五类业务写入全部携带；旧客户端没有该头时仍兼容原保存行为，但没有安全重复请求保证。

1. 验证会话、Origin、CSRF、X-Account-Id 以及请求结构。
2. 事务锁定账户行；按账户与编号查找 WriteReceipt。
3. 已有回执且方法、路径及请求体摘要相同：直接返回首次结果，不再检查旧版本或写业务表。
4. 同编号内容不同：409 REQUEST_KEY_REUSED。新编号仍执行原 expectedRevision、expectedVersion 或体重原值检查。
5. 执行业务操作，成功响应和业务修改一起事务提交。回执写失败，业务修改也回滚。

JSON 对象键排序后计算 SHA-256，数组顺序仍有意义。失败请求不留成功回执；重试不修改请求体和版本条件。回执在登录账户内部使用，不提供公开读取端点，退出或来源伪造不能重放。当前回执保留到账户删除，不能提前删除后允许旧请求重新执行。

网络、503、429 保留待同步；登录失效、CSRF 失效或账户切换停止本次请求，刷新并登录原账户后仍能用原编号核对；业务 409、输入 400 等保留为待核对状态。服务器返回首次回执只证明那次操作成功，因此重试完成后重新加载最新事实，避免用老响应覆盖后来修改。

## 字段与代码学习

第七份数据库迁移新增 WriteReceipt，共 12 张表、87 个字段（含迁移管理表），新增表和字段都有 PostgreSQL 中文注释；字典见 BACKEND-FIELDS.md。

- `public/sync-outbox.js`：账户专属存储、跨页面锁、先暂存后发送、成功清理与失败分类。
- `public/account-api.js`：请求编号、20 秒等待、原请求重试与账户隔离。
- `public/sync-view.js`：待同步提示、下载、重试、放弃；只更新提示，不清空表单。
- `server/reliable-write.ts`：同一事务内检查摘要、返回回执或完成业务写入。
- `server/private-routes.ts` / `server/write-routes.ts`：原有版本检查和历史快照规则继续生效。
- `test/sync-outbox.test.js` / `server/test/reliability.test.ts`：存储失败、损坏保留、并发、认证恢复、响应丢失与整批回滚的具体示例。
