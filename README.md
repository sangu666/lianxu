# 练序 / Lianxu

一个面向新手居家与健身房用户的开源健身教练项目。

**已发布版本：0.2.0；main 源码已接入本机账户数据库、旧备份迁移和失败写入重试，仍为开发原型。真实 AI、云端同步和身体成分估计尚未实现。**

本地开发已新增 TypeScript + Fastify + Prisma + PostgreSQL 后端，提供 1,342 条公开动作文字资料及注册、登录、退出、个人读取与资料保存接口。第四步已接入账户页面：资料、计划、训练组与体重按登录账户读写本机数据库；未登录仍为浏览器模式，旧记录未自动迁移。打开 http://127.0.0.1:3100/，详见 [页面接入与验收](docs/BACKEND-INTEGRATION.md)。启动：安装依赖后执行 `npm run backend:local`，详见 [后端启动与学习](docs/BACKEND-SETUP.md)、[数据模型与接口](docs/BACKEND-DESIGN.md) 和 [账户与隔离](docs/BACKEND-ACCOUNTS.md)。

main 分支已包含 iOS 风格界面、资料扩展、中文动作库与全库计划编辑，以及后端第一至六步；现有 v0.2.0 Release 仍保留原版本，本次仅同步源码。详见 [资料与筛选规则](docs/PROFILE-DATA.md)。

## 当前可用

- 六个页面：今日概览、身体资料、训练计划、训练记录、饮食示例、进展回顾。
- 根据训练经验、环境和每周3/4次确定基础模板；具体设备、单次时间、动作偏好及主动排除类型参与筛选，缺项明确提示。
- 一次训练包含多个动作和组：支持开始/完成、逐组新增/编辑/删除、日期与备注修改、整次删除。
- 刷新恢复进行中的训练，按动作与单位查看上次成绩、填入上次最后一组。平板支撑按秒记录。
- JSON完整备份、导入预览、训练合并去重与完整恢复；记录体重与日期。
- 三视角照片在浏览器临时预览；不上传，刷新清除。
- 手动恢复反馈演示减量，确认后保留模板版本快照。
- 资料、训练、体重与版本快照保存在当前浏览器。

初始资料是虚构示例。模板和饮食数值用于说明交互，尚未经过个人分析或专业审查。目标、身高、体重目前用于资料记录，不会改变模板或计算个人热量。

## 本地运行

安装 Node.js 22.18或更高版本。在项目目录运行：

```sh
npm start
```

浏览器打开 `http://127.0.0.1:3000`。运行应用无需安装依赖或提供任何 API 密钥。Windows若不允许运行npm.ps1，可使用 `npm.cmd start`。

## 开发与检查

```sh
npm ci
npm run check
npm run format:check
```

前端原型运行时仅使用浏览器与Node标准库；本地后端需要安装 package.json 中的依赖。Prettier只用于开发格式检查，不参与应用运行。`npm run build`将公开前端资源输出至 `dist/`，可部署到静态托管；静态部署不包含后端服务，浏览器个人记录不进入构建文件。

## 功能边界与数据

没有真实 AI、照片身体分析、个人营养计算或长期照片存储。后端账户已实现，但页面尚未接入账户隔离或同步。版本快照可查看，但当前仅支持恢复基础模板，尚无任意历史版本回滚。未点击保存的表单输入不算已记录，切换动作或刷新会丢失这些输入。此版本不作为个人训练或营养处方。

本地存储不是加密健康档案。清除按钮清空当前v0.2数据；v0.1原始存储键保留用于恢复。新旧记录均在浏览器中，未加密。不要把个人照片、真实记录、密钥或数据库提交到GitHub。当前没有远程接口；后续接入AI时需单独明确处理目的和数据去向。
