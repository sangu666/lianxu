# 练序 / Lianxu

一个面向新手居家与健身房用户的开源健身教练项目。

**当前版本：0.1.0，可运行的交互原型。真实 AI、认证、云端数据库和身体成分估计尚未实现。**

## 当前可用

- 六个页面：今日概览、身体资料、训练计划、训练记录、饮食示例、进展回顾。
- 根据训练经验、哑铃居家/健身房设备和每周3/4次切换规则模板。
- 记录每组重量、次数、RIR、疼痛反馈，记录体重与日期。
- 三视角照片在浏览器临时预览；不上传，刷新清除。
- 手动恢复反馈演示减量，确认后保留模板版本快照。
- 资料、训练、体重与版本快照保存在当前浏览器。

初始资料是虚构示例。模板和饮食数值用于说明交互，尚未经过个人分析或专业审查。目标、身高、体重目前用于资料记录，不会改变模板或计算个人热量。

## 本地运行

安装 Node.js 22或更高版本。在项目目录运行：

```sh
npm start
```

浏览器打开 `http://127.0.0.1:3000`。运行应用无需安装依赖或提供任何 API 密钥。Windows若不允许运行npm.ps1，可使用 `npm.cmd start`。

## 开发与检查

```sh
npm ci
npm run check
npm run format:check
```

运行时仅使用浏览器与Node标准库。Prettier只用于开发格式检查，不参与应用运行。`npm run build`将公开前端资源输出至 `dist/`，可部署到静态托管；浏览器个人记录不进入构建文件。

## 功能边界与数据

没有真实 AI、照片身体分析、个人营养计算、长期照片存储、多用户账户或同步。记录暂不支持逐条编辑/删除，版本快照可查看，但当前仅支持恢复基础模板，尚无任意历史版本回滚。此版本不作为个人训练或营养处方。

本地存储不是加密健康档案。清除按钮会移除当前浏览器资料与记录。不要把个人照片、真实记录、密钥或数据库提交到GitHub。当前没有远程接口；后续接入AI时需单独明确处理目的和数据去向。
